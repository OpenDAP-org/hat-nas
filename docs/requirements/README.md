# NAS HAT requirements

Requirements for this project.

| ID | Requirement | Priority | Status |
|---|---|---|---|
| NAS-001 | This HAT is a complete project: hardware, case, firmware, software, OpenDAP OS package and its own tooling. | must | Confirmed |
| NAS-002 | Its OpenDAP OS software shall be a custom implementation built on popular open-source software for its domain, optimized for this HAT and the board. | must | Confirmed |
| NAS-003 | It shall mount through the HAT Case Standard. | must | Confirmed |
| NAS-004 | It may include on-board AI features. | should | Draft |
| NAS-005 | The HAT shall provide SSD storage. | must | Confirmed |
| NAS-006 | The HAT shall provide Ethernet ports. | must | Confirmed |
